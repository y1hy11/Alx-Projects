# my-company

A multi-page company website with client-side routing built as part of the **ALX Cohort 5 Frontend Course**. This project demonstrates React Router for navigation across four static pages.

## Features

- React Router DOM for client-side routing (`BrowserRouter`, `Routes`, `Route`)
- Navigation using `<Link>` components
- Four pages: Home, About, Services, Contact
- Contact page with a form using `useState`
- Inline styles for layout

## Technologies

- React 19
- React Router DOM 7.7
- Vite

## Getting Started

```bash
npm install
npm run dev
```
