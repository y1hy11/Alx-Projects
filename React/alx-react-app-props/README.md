# alx-react-app-props

A project focused on advanced data flow patterns using React Context API, built as part of the **ALX Cohort 5 Frontend Course**. This project demonstrates global state management across nested components without prop drilling.

## Features

- React Context API (`createContext`, `useContext`)
- Context Provider pattern wrapping the entire app
- Nested component tree consuming context: `App` -> `ProfilePage` -> `UserInfo` -> `UserDetails`
- Multiple consumer components sharing the same context

## Technologies

- React 19 (Context API)
- Vite

## Getting Started

```bash
npm install
npm run dev
```
