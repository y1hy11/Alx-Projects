# recipe-sharing-platform

A visually polished recipe sharing platform built as part of the **ALX Cohort 5 Frontend Course**. Features a homepage with recipe cards, detailed recipe views, and an add-recipe form with comprehensive validation.

## Features

- React Router with 3 routes: `/`, `/recipe/:id`, `/add-recipe`
- Homepage with recipe image cards, hover effects, and grid layout
- Recipe detail page with images, timing info, ingredients, and step-by-step instructions
- Add recipe form with extensive validation (required fields, URL pattern, minimum requirements)
- Success toast notification
- Loading and 404 states
- Tailwind CSS utility classes and custom styling

## Technologies

- React 19
- React Router DOM 7.8
- Tailwind CSS 4.1
- Vite

## Getting Started

```bash
npm install
npm run dev
```
