# recipe-sharing-app

A recipe sharing application with routing, CRUD operations, search filtering, favorites, and recommendations, built as part of the **ALX Cohort 5 Frontend Course**. State management powered by Zustand.

## Features

- React Router with 5 routes: `/`, `/add`, `/recipe/:id`, `/favorites`, `/recommendations`
- Zustand store for centralized state management
- CRUD operations: add, edit, delete recipes
- Search filtering by title via Zustand store
- Favorites list derived from store
- Recommendations based on favorites
- Full recipe details view

## Technologies

- React 19
- React Router DOM 7.7
- Zustand 5.0
- Vite

## Getting Started

```bash
npm install
npm run dev
```
