# form-handling-react

A form handling demonstration project built as part of the **ALX Cohort 5 Frontend Course**. This project showcases two approaches to form management: manual validation with React `useState` and library-based validation using Formik with Yup.

## Features

- Controlled form inputs with `useState`
- Manual form validation (required field checks)
- Form submission handling with `onSubmit` and `preventDefault`
- Formik library integration (`<Formik>`, `<Field>`, `<ErrorMessage>`)
- Yup validation schema (min length, required, email format)
- Async submission simulation with loading/submitting states

## Technologies

- React 19
- Formik 2.4
- Yup 1.7
- Vite

## Getting Started

```bash
npm install
npm run dev
```
