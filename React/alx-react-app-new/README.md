# alx-react-app-new

An extension of the introductory React app that adds state management, built as part of the **ALX Cohort 5 Frontend Course**. This project demonstrates React's `useState` hook for interactive UI.

## Features

- All features from the basic React app (static components + props)
- State management with `useState` hook
- Counter component with increment, decrement, and reset functionality
- Event handling (button clicks)

## Technologies

- React 19
- Vite

## Getting Started

```bash
npm install
npm run dev
```
