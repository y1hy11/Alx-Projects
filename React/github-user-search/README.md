# github-user-search

A GitHub user search application built as part of the **ALX Cohort 5 Frontend Course**. Users can enter a GitHub username to retrieve profile information via the GitHub REST API, styled with Tailwind CSS.

## Features

- API integration with Axios to GitHub's REST API
- Async data fetching with error handling
- Search form with input and button
- User profile card: avatar, name, username, location, bio, followers/following/repos stats
- Tailwind CSS utility classes for responsive styling

## Technologies

- React 19
- Axios 1.11
- Tailwind CSS 3.3
- Vite

## Getting Started

```bash
npm install
npm run dev
```
