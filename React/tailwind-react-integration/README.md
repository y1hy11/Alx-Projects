# tailwind-react-integration

A minimal project demonstrating Tailwind CSS v4 integration with React, built as part of the **ALX Cohort 5 Frontend Course**. Features a single user profile card component styled entirely with Tailwind utility classes.

## Features

- Tailwind CSS v4 with `@tailwindcss/vite` plugin
- Responsive design with breakpoints (`sm:`, `md:`)
- Utility classes for layout, shadows, and hover effects
- Transitions and animations (`hover:scale-110`, `transition-transform`)
- Single reusable `UserProfile` component with avatar, name, and bio

## Technologies

- React 19
- Tailwind CSS 4.1
- @tailwindcss/vite 4.1
- Vite

## Getting Started

```bash
npm install
npm run dev
```
