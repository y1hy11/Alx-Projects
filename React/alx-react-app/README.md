# alx-react-app

A basic introductory React application built as part of the **ALX Cohort 5 Frontend Course**. This project demonstrates the fundamentals of JSX, functional components, and props in React.

## Features

- Functional components: `Header`, `MainContent`, `Footer`, `WelcomeMessage`, `UserProfile`
- Props passing (`UserProfile` receives `name`, `age`, `bio`)
- Component composition
- JSX rendering

## Technologies

- React 19
- Vite

## Getting Started

```bash
npm install
npm run dev
```
