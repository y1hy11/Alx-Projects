# react-todo

A fully-featured Todo List application with CRUD operations and comprehensive testing, built as part of the **ALX Cohort 5 Frontend Course**.

## Features

- Add todos with form input and Enter key support
- Toggle completion with strikethrough styling
- Delete todos with button
- Real-time statistics (total, completed, remaining)
- Edge case handling: empty todos, whitespace trimming
- Jest + React Testing Library test suite covering full workflow

## Technologies

- React 19
- Jest 29
- @testing-library/react 16
- Vite

## Getting Started

```bash
npm install
npm run dev
```

## Running Tests

```bash
npm test
```
